● COMPARATIVE ANALYSIS
Part 2: Mobile App Repository Comparison & Audit Repository: Hakiri-APP (Flutter)
Audit Verdict on Mobile Repository: The mobile repository (Hakiri-APP, Flutter Dart, 11,100 lines) was a visual prototype shell, not an operational app. It did not record audio, had no speech-to-text, had no AI evaluation, dummy login without password checks, and a fake paywall. Our Action: Rather than discarding the client's investment in mobile design, we salvaged every concept (the 7-step assessment, the 4 pillars, gym drills, and pricing tiers) and engineered them into working software in Hakkiri Studio.
Feature Dimension Mobile App Repository (Hakiri-APP) Hakkiri Studio Pro (Current Web Studio)
Codebase & Language Flutter (Dart), 11,100 lines, 14 commits. Last commit October 7, 2026. Next.js 16.4 (App Router), React 19, TypeScript, Tailwind CSS, Zod.
User Authentication Fake: _handleLogin navigated directly to Home without checking credentials. Hardcoded user usr_hakkiri_demo_user. Real: PBKDF2/SHA-512 password encryption, persistent store, session cookies, dynamic name/role binding across headers & rails.
Microphone & Audio Non-existent: No recording package in pubspec.yaml, no iOS/Android permissions. Waveform was a looping animation. Fully Working: Web Audio API & MediaRecorder capturing real audio blobs, waveform visualization, and instant playback.
Speech-to-Text (STT) Fake: Timer countdown ended by submitting a single hardcoded sentence as the "transcript". Real: Deepgram Nova-3 integration with word-level timestamps and browser Web Speech fallback.
AI Scoring Engine Dummy Strings: 100-line string rule set. Hardcoded 94% intelligibility, 70% action verbs, invented timestamps. Real AI Engine: Claude Sonnet 5 + Haiku 5.5 scoring checked against Zod schemas, with algorithmic cadence and filler metrics.
Diagnostic Assessment 7 screens kept in memory only; lost completely on app restart. Never saved to database. 7-step interactive diagnostic flow with custom visual artwork, persistent state, and automated 4-week plan generation.
Communication Gym Single mock drill screen with hardcoded simulated feedback. 6 distinct interactive drill modes (Think First, PREP, Filler Eliminator, Brevity, Metric Impact, Tone).
Analytics Dashboard Hardcoded literal numbers (3.4, 3.8, 3.1, "Think First 3.7 Today"). Interactive 4-Pillar radar dashboard, historical trend graphs, XP streaks, and targeted fixes.
Interview Simulation Not built in mobile app (mobile was conceptual daily drills only). Full job interview simulator with CV parser, AI voice interviewer (Sam), and adaptive follow-up probing.
Presentation Lab Not built in mobile app. Complete deck timing lab: PDF/PowerPoint slides, overrun alerts, and simulated executive audience Q&A.
STAR Story Bank Not built in mobile app. Situation, Task, Action, Result vault with automated interview question fit mapping.
Paywall & Billing Fake: Sets an in-memory string and navigates to Home without taking payment. "Restore purchase" had an empty handler. Foundation, Accelerator, and Executive Mastery plans with monthly/annual toggle and transparent AI compute unit costs.
Automated Tests 1 test (only checked if splash screen appeared). 197 automated unit tests (Vitest) + Playwright end-to-end test suite. 100% green.
Client Benefit: Rather than starting from scratch, the client now possesses a fully functional web platform containing all features originally envisioned for both web and mobile, backed by real AI and real audio engineering.
